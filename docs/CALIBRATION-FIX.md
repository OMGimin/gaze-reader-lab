# 보정 실패 진단과 수정

2026-10-22. 실제 사용자에게 보정 실패가 보고되어 코드와 합성 입력으로 조사했다. 사용자의 영상·보정 표본을 수집하지 않았으므로 아래 결함이 해당 실패의 원인이라고 확정할 수는 없다.

## 재현한 결함

1. **작은 머리 움직임이 시선 신호로 학습됨.** 이전 회귀는 눈 특징과 자세 특징 모두를 표준화했다. 학습 중 점과 연관된 작은 머리 변화가 확인 단계에서 사라지면, 정확한 합성 눈 신호가 있어도 위·아래 추정이 중앙으로 압축됐다. 자세 제한을 넘지 않는 변화로 재현했다. 이제 눈 특징 4개만 회귀에 사용하고 자세는 안전 정지 기준으로 남긴다.
2. **비정사각 영상의 좌표 단위 혼합.** 정규화된 x/W와 y/H로 거리와 내적을 계산해 같은 물리적 눈 모양도 영상 종횡비·머리 기울기에 따라 다른 특징이 나왔다. 이제 양 축을 영상 너비 기준 단위로 맞춘다. 미리보기 CSS 반전은 추론 입력에 적용되지 않으며, 반전 오류는 발견하지 못했다.

수정 전 회귀 테스트 세 개가 실패했고 수정 후 통과했다. 이는 수학적·구현상 결함의 증거이며 실제 웹캠 정확도 향상률의 측정값은 아니다.

## 측정과 안내 개선

- 첫 점은 중앙이다. 점마다 1.2초 워밍업 후 새로운 표본 24개를 받는다. 중복 영상 프레임은 추론에서 건너뛴다.
- 수집이 늦거나 얼굴 추적·자세가 불안정하면 해당 점에서 멈춘다. **이 점 다시 측정**을 누르면 앞서 완료한 점은 유지하고 그 점만 다시 받는다.
- 학습점의 특징 중앙값·MAD 기반 이상치 검사와 점별 동일 가중치로 표본 수와 순간 잡음의 영향을 줄인다. 정규화된 행렬에 ridge 0.01을 적용한다.
- 학습에 쓰지 않은 5점은 모든 유효 표본으로 검증한다. 평균 오차 0.10 이하, 최대 0.18 이하, 위/중앙/아래 각 80% 이상 일치 기준은 그대로다. 검증 오차를 보고 표본을 제거하지 않는다.
- 실패 진단에 평균·최대 오차, 각 명령 영역 일치율, 점별 표본과 오차를 표시한다. 실패 모델은 적용하지 않고 시작 버튼을 잠근다. 진단은 화면과 메모리에만 존재한다.

## 사용자의 재시험

`npm run build` 후 로컬 페이지를 새로고침한다. 확장을 설치해 사용 중이면 `chrome://extensions`에서 확장을 새로고침하고 읽기 페이지도 다시 연다. 카메라 창은 읽기 창 옆에 배치한 다음, 사용자가 직접 카메라를 켜고 읽기 창으로 돌아와 **시선 보정**을 누른다. 머리를 정면으로 유지하고 중앙 안내 문장보다 밝은 점을 따라본다. 약 40초가 필요하다. 실패하면 진단의 평균/최대 오차와 위/중앙/아래 일치율을 확인한다. 영상이나 눈 특징을 저장·전송할 필요는 없다.

여전히 실패할 수 있다. 수직 홍채 이동은 작고 눈꺼풀·안경 반사·자세 변화·웹캠 위치의 영향을 받는다. 확인 단계는 평활화 전 표본을 판정하므로 순간 잡음에도 엄격하다. 임계값 완화보다, 동의한 실제 사용자에게서 원인별 실패와 명령 구분 성능을 먼저 평가해야 한다.
