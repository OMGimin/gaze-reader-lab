# 사용자가 직접 수행할 확인

아래는 아직 수행하지 않은 실제 장치·사람 검증이다. 카메라와 확장 설치 권한은 사용자가 직접 선택해야 한다. 접근성 권한은 요구하지 않는다.

1. 로컬 모의 체험에서 중앙→아래, 반복 방지, Esc, 되돌리기를 확인한다.
2. 동의할 경우에만 카메라를 켜고 9점 보정 + 5점 확인을 수행한다. 안경 유무·조명·화면 크기와 통과/실패만 기록한다. 얼굴 영상·좌표 데이터는 기록하지 않는다.
3. 다음 10회·이전 10회를 의도적으로 요청한다. 정확히 한 번씩 움직였는지, 재준비 없이 반복하지 않는지 수동으로 센다.
4. 평소처럼 5분 동안 읽으며 의도하지 않은 이동 횟수를 센다. 초기 목표는 0회지만 현재 달성 증거는 없다.
5. 얼굴을 가림, 카메라 창 닫기, 다른 탭 선택, 1초 눈 감기, 수동 휠, 창 위치 이동을 차례로 시험한다. 어떤 경우에도 이후 자동 이동이 이어져서는 안 된다.
6. 독립 카메라 창을 읽기 창 옆에 놓고 최소화/가림 시 입력 지연 정지를 확인한다. 재개는 읽기 창의 버튼을 사용한다.
7. 로컬 테스트가 괜찮을 때만 Chrome 확장을 직접 설치한다. 자신의 정상 접근 권한으로 열린 네이버 웹툰 회차에서 시험한다. 로그인·결제·연령 확인은 이 시제품의 역할이 아니다.
8. 끝나면 카메라 끄기, 카메라 창 닫기, 필요하면 확장 제거를 수행한다. macOS 카메라 표시등도 확인한다.

실제 시선 추정에 실패해도 모의 입력 테스트의 통과를 근거로 사용 가능하다고 판단하지 않는다. 임상적·보조공학적 적합성 평가는 별도다.
