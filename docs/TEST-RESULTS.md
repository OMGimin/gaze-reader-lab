# 검증 결과

검증일: 2026-10-22. 사용자의 **Mac에 설치된 Google Chrome**을 headless + 격리된 임시 프로필로 실행했다. macOS 26.6.2 arm64, Chrome 155.0.8059.85, Node 26.7.0, Playwright 1.56.1. 개인 탭·로그인·확장 설치를 변경하지 않았다. 인앱 브라우저 미리보기는 확장 통합 검증으로 계산하지 않았다.

| 검증 | 결과 | 재현 / 증거 |
|---|---|---|
| 웹·확장 번들 | 성공 | `npm run build` |
| 단위·모의 연결 | **22개 통과** | `npm test`, `tests/*.test.mjs` |
| Mac Chrome UI | **9개 통과** | `npm run test:ui`, `tests/ui/` |
| 실제 MediaPipe 초기화·빈 영상 추론 | 로컬 WASM/모델 로드 및 자체 생성 빈 캔버스에서 0명 추론 | [모델 화면](model-check.png) |
| 모델 점검 중 외부 요청 | 0건 | UI request 검사, CSP `connect-src 'self'` |
| 실제 카메라 | 자동 테스트에서 사용하지 않음 | getUserMedia를 모의 함수로 교체 |
| 카메라 권한 거절 | 모의 NotAllowedError 처리 통과 | UI 테스트 |
| 전체 보정·명령·안전 정지 | 합성 특징으로 통과 | UI 테스트 |
| 보정 중단·같은 점 재시도·자세 변경 | 통과 | `calibration.spec.js` |
| 확인 실패 진단·모델 미적용 | 통과 | [합성 실패 진단](calibration-fix/diagnostics.png) |
| 뷰포트 | 1280×900, 760×900 확인 | [제어 패널](reader-controls.png), [좁은 화면](narrow.png) |

보정 수정 전에는 머리 자세 혼동, 영상 내 회전, 종횡비 회귀 테스트가 실패했다. 수정 후 모두 통과했다. 학습 표본의 순간 이상치·불균등한 수, 확인 표본의 이상치를 숨기지 않는 동작, 낮은 평균 오차에도 명령 구분 실패를 거절하는 동작을 추가 검증했다. 독립 코드 검토에서 최종 보정 변경의 중대한 결함은 발견되지 않았고, 검토자가 단위 테스트 22개를 별도로 실행해 통과를 확인했다.

기존 테스트는 중앙 준비, 1회 이동·반복 방지, 위/아래, 추적 지연, 비정상 좌표, 깜박임, 보정 부족, URL 제한, 선택 탭 라우팅, 카메라 종료와 비동기 경합을 다룬다. Chrome API 연결 테스트는 모의 객체를 사용한다. 원시 로컬 실행 로그와 보고서는 개인 경로·환경 정보를 포함할 수 있어 공개 저장소에서 제외했다. 실행하면 `playwright-report/index.html`에서 자체 결과를 볼 수 있다.

## 근거의 한계

- 사용자가 실제 보정 실패를 보고했다. 이번 수정 후 **사람의 시선으로 재시험하지 않았다**. 합성 특징은 실제 홍채 잡음·눈 형태·눈꺼풀·안경·머리 변화의 분포를 재현하지 못한다.
- 실제 카메라의 FPS·CPU·장시간 안정성, 보정 성공률, 읽기 중 오작동률은 미측정이다.
- Chrome 확장 실설치·카메라 권한 승인은 사용자가 해야 한다. 실제 네이버 회차에서의 통합 스크롤은 미검증이며 루트 window 스크롤만 지원한다.
- 카메라 창 가림·최소화·절전은 실제 스트림으로 미검증이다. 입력이 300ms 끊기면 정지하는 로직만 시험했다.
- 0건 외부 요청 결과는 모델 초기화·빈 프레임 추론 범위다. 실제 카메라 네트워크 측정 결과로 일반화하지 않는다.
- 공개 소스의 Linux Chromium 실행 경로는 제공하지만 Mac에서 Linux 검증을 했다고 주장하지 않는다.
